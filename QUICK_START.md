## 🐛 COMMON ISSUES & FIXES

### Server Won't Start
```
Error: Port 3000 already in use
Fix: Kill process on port 3000 or change port in .env
```

### Page Shows Errors
```
Error: Cannot load from server
Fix: Make sure npm start is running
Fix: Check http://localhost:3000 (not file://)
```

### Admin Login Fails
```
Error: Login not working
Fix: Check username: admin, password: admin123
Fix: Make sure server is running
```

### Animations Not Smooth
```
Issue: Choppy animations
Fix: Update browser to latest version
Fix: Close unnecessary tabs
Fix: Check GPU acceleration is on
```

### Cart Not Updating
```
Issue: Items don't appear
Fix: Refresh page (Ctrl+R)
Fix: Check localStorage not full
Fix: Clear cookies/cache
```
