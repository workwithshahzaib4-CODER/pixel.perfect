# Product Photography Plan

The current catalog does not include reliable sales analytics, so this first batch uses the first ten products marked as featured. Replace the selection with actual best sellers once order data is available.

For each product, add five real local images under `assets/products/` and reference them in `data/products.json`:

- `images`: clean artwork/product image
- `mockups`: framed or mounted product view
- `roomImages`: real room or desk placement
- `packagingImages`: packaging and unboxing view
- `sizeComparisonImages`: size next to a ruler, hand, desk, or wall reference

## Review trust rules

- Never create fictional reviews or use stock photos as customer proof.
- Ask real buyers for an order ID and checkout phone when they submit a review.
- The server marks a review as verified only when the order and purchased product match.
- Keep unverified reviews labelled as pending or customer-submitted until approved.
- Add the customer's real city only with permission.
- Use customer wall photos only with permission.
